# 糰糰島

溫暖的2D像素生活遊戲開發版。可單機種田、採集、料理與建造，隨故事解鎖島民照料及供水、林業加工。

本批預先發行試玩包：**0.50-dev r23**。

- [下載 Linux 世界伺服器包](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r23/TuanIslandServer-0.50-dev-r23-linux-x64.zip)
- [更新說明與檔案校驗](https://github.com/and910805/tuan-island/releases/tag/v0.50-dev-r23)

r23整合播種落地回饋、站立居民回應及故事BGM返回修正，部署包增加純密碼房離線備份。主畫面應顯示r23，選「住進自己的小島」可單機玩，不需要IP。

協定48，存檔26。實測範圍是本機Windows EXE連獨立Linux世界、種田與重啟保存，以及隔離安裝、舊存檔副本與解除安裝留檔；不是第二台電腦或公開雲端驗收。雲端沒有隨本次發布切換。

r22與更新版本支援簽章更新來源；r21與更早需先手動安裝新版。正式更新清單在二進位公開核對後另行發布，驗證結果以Release附件為準。
