# 糰糰島

溫暖的2D像素生活遊戲開發版。可以單機種田、採集、料理與建造，隨故事逐步解鎖島民照料及供水、林業加工。

目前試玩包：**0.50-dev r20**。

- [下載 Windows 安裝檔](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r20/TuanIslandSetup-0.50-dev-r20.exe)
- [下載 Linux 世界伺服器包](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r20/TuanIslandServer-0.50-dev-r20-linux-x64.zip)
- [更新說明與檔案校驗](https://github.com/and910805/tuan-island/releases/tag/v0.50-dev-r20)

安裝後確認主畫面左下為r20，選「住進自己的小島」即可單機玩，不需要IP。這版新增小羊躲雨、八秒糯米雞抱抱，並保留既有梳毛與農事動作。

多人客戶端與世界伺服器都需使用協定47。已完成本機Windows EXE連Linux容器、互動及資料重啟驗證；雲端尚未切換到這版，公開WSS與跨電腦仍待驗收。自動更新清單尚未配置，請先由上方Release下載。

原始碼位於[game](game/README.md)，引擎為Godot4.7.2。完整遊戲仍在開發，這是供試玩的預先發行版。
