# 糰糰島

台灣小島題材的 2D 像素生活模擬遊戲，支援 Windows 單機與多人同島。

目前試玩版為 **0.50-dev r26**。下載遊戲後，選擇「住進自己的小島」即可單機遊玩。

- [Windows 免安裝版](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r26/TuanIslandWindows-0.50-dev-r26.zip)
- [Windows 安裝版](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r26/TuanIslandSetup-0.50-dev-r26.exe)
- [發行說明與 Linux 伺服器包](https://github.com/and910805/tuan-island/releases/tag/v0.50-dev-r26)

本版多人協定 53，存檔格式 27。遊戲以 Godot 4.7.2 開發，原始碼在 [game](game)，部署說明在 [game/deploy](game/deploy/README.md)。
