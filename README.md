# 糰糰島

溫暖的2D像素生活遊戲開發版。可單機種田、採集、料理與建造，隨故事解鎖島民照料及供水、林業加工。

本批試玩包：**0.50-dev r21**。

- [下載 Windows 安裝檔](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r21/TuanIslandSetup-0.50-dev-r21.exe)
- [下載 Linux 世界伺服器包](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r21/TuanIslandServer-0.50-dev-r21-linux-x64.zip)
- [更新說明與檔案校驗](https://github.com/and910805/tuan-island/releases/tag/v0.50-dev-r21)

安裝後確認主畫面左下為r21，選「住進自己的小島」即可單機玩，不需要IP。新增奶糖牛摸頭後的短程跟隨、釣魚等待及漁獲擺動、加工成品落架，並減少重複提示；保留羊躲雨及雞抱抱等既有內容。

多人客戶端與世界伺服器需同用協定48；r20協定47不能混用。正式Windows EXE已連本機Linux容器測試照料與重啟保存；雲端尚未切換r21，公開WSS與跨電腦仍待驗收。自動更新清單尚未配置，請先由上方Release下載。

原始碼位於[game](game/README.md)，引擎Godot4.7.2。本tag與release/r21-20261118分支對應本批來源；預設分支及雲端不會因本次Release自動升級。完整遊戲仍在開發，這是預先發行試玩版。
