# r22 正式更新來源準備與本機包驗收

本批build22／protocol48／save26，新增正式RSA發行公鑰及固定公開HTTPS更新清單設定。沿用既有驗簽、下載、核對兩個執行檔、啟動回報與可回復更新流程。r21及更早公開檔未配置公鑰及來源，需先手動安裝一次r22；後續新版本才會提示更新。

發行私鑰保存在專案外、限制本機目前使用者與SYSTEM存取；原始碼及Windows包只含公鑰。公鑰SPKI DER SHA256為4738407f46dd3baeed9d8e8747c57d3ea8ebe784701b109059208531aa4bc232。簽章清單來自實際完成的Windows ZIP，包含ZIP大小與SHA256、EXE及存檔DLL兩個雜湊。以正式公鑰在Godot驗證實際簽章成功，目前版本不重複提示；私鑰不進專案或發行包。

Windows匯出EXE已連本機獨立Linux r22容器，原牛卡照料48畫格、背包相機不變。雙客戶端12項及容器重啟4項通過，保留兩原玩家、親密度與照料時間；使用同機隔離世界及預置野餐／站位，不是公開雲端。
