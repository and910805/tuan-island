# 操作提示共用位置與內容寬度 — 2026-11-18

## 進展與基準

前一目標回合有進展：新增並原生驗證林業完工落架，不是等待或重述狀態。接續規劃書的 UI 資訊層級與不遮擋場景要求，檢查實機加工畫面發現「已排入加工」舊訊息和「鋸木台完工」字幕各自佔一條橫幅。基準圖 work/processing-finish-qa/before/all_ready.png 顯示兩條重疊資訊；舊操作橫幅固定740px，短訊息也佔很寬。

## 修改

Main 的操作訊息與活動字幕共用同一位置。新成功字幕出現時清除較早的操作橫幅；下一個動作結果取代舊字幕。新錯誤會立即顯示，尚在時限內的錯誤不被自動背景完工字幕取代。保留活動字幕開關與魚咬鉤高於背景完工的既有優先級；關閉字幕不會關閉一般操作結果。

共用排版依實際字型與文字寬度計算，短訊息最小220px、長訊息最多740px且受可用畫面限制，維持自動換行。藍圖側欄開啟時仍避讓側欄；提示共用原本工具提示上方的位置，不再上下疊兩條。

不改任務、材料、加工、背包或存檔資料，不新增網路欄位。只清除過期的視覺訊息，錯誤與最新領取結果仍可見。
