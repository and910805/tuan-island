# 釣魚生活感動畫 — 2026-11-18

## 本輪範圍

使用者希望增加動畫。先錄下目前釣魚流程，確認已有拋竿、水波、魚影、咬鉤及收魚；本輪補強等待時僵硬的角色與魚竿，以及收魚後漁獲的短暫擺動。這是 r20 之後尚未發布的客戶端修改，公開 r20 安裝檔沒有包含本輪動畫。

## 修改

- 等待時身體輕微左右傾、持竿手上下各約一個像素、魚竿小幅擺動。
- 漁獲收回後使用原有魚種 PNG 作短暫衰減位移，不添加假魚種或新的獎勵。
- 低動態模式維持靜態角色及道具回饋；沿用攝影模式傳入的低動態旗標。
- 僅修改 FishingArt 和渲染驗證，不改鏡頭、地圖、碰撞、背包、存檔或多人通訊。

## 實際執行

Windows 原生 Godot 4.7.2 / Compatibility / AMD GPU，1280×800。以 capture_fishing_feedback.gd 建立隔離世界、設定岸邊測試站位，經既有 session.perform 完成拋竿→等待→咬鉤→收魚→另次拋竿後移動取消。這是程式驅動實際遊戲，不是人工滑鼠試玩或 Zeabur 連線。

修改前、修改後及低動態各 57 張真實畫面，三次皆魚數 0→1，重載保留，取消沒有增加魚。查看修改後 016 等待幀與 040 收魚幀，魚竿及實際漁獲可辨識，沒有新增遮擋提示。

驗證：FISHING_ART_TESTS checks=51 failures=0；FISHING_FEEDBACK_TESTS checks=30 failures=0。涵蓋等待持竿不同姿勢、角色呼吸方向、低動態靜止、原拋竿/咬鉤/收魚/取消及魚種圖示。

證據：work/fishing-life-motion/{before,after,reduced}/sequence.json 與原生 PNG。outputs/fishing-life-motion/{before,after,reduced}.gif 以錄影時間合併原生畫面，裁切角色及浮標區域、最近鄰放大兩倍，未合成新動作。

## 判斷與限制

等待動作刻意細微；咬鉤與收魚保留較大動作區分。這不是完整四方向手臂分幀或全場景動畫完成。畫面仍可見舊版區域素材交界與重複釣魚文字，應另行改善，沒有在本輪視為解決。Windows 遊戲沒有行動版，本輪未做手機測試、公開多人或重新打包。

下一輪優先挑動作與回饋缺口，而非讓所有物件持續抖動；可續做農作收穫及加工出料的因果回饋。
