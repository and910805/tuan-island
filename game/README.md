# 糰糰島 Windows 多人像素生活遊戲

Godot 4.7.2 原生2D像素生活模擬遊戲開發版，包含耕作、建造、島民故事及供水／林業加工等逐步解鎖的玩法。

目前公開試玩包為 **0.50-dev r20**，多人協定 **47**、世界存檔格式 **26**。客戶端及世界伺服器需同版；版本資料以[release.json](release.json)為準。

- [Windows安裝包](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r20/TuanIslandSetup-0.50-dev-r20.exe)
- [Linux世界伺服器包](https://github.com/and910805/tuan-island/releases/download/v0.50-dev-r20/TuanIslandServer-0.50-dev-r20-linux-x64.zip)
- [r20更新說明與驗證範圍](https://github.com/and910805/tuan-island/releases/tag/v0.50-dev-r20)

選「住進自己的小島」可單機遊玩，不需要IP。r20加入小羊躲雨及糯米雞短暫抱抱，保留既有存檔及生產規則。Windows EXE與本機獨立Linux世界程序已有連線、照料互斥及重啟驗證；公開雲端WSS、完整真人旅程及整體規劃仍在開發驗收中。

版本更新網址尚未配置為公開簽署清單，現階段請從上方Release下載安裝包。部署及持久資料設定見[部署說明](deploy/README.md)。

## 已有內容

### Windows 版本更新提示

客戶端可在啟動時讀取 HTTPS 版本清單。發行設定需將 `application/config/update_manifest_url` 指向公開 JSON，欄位包含 `latest_version`、`minimum_version` 與 HTTPS `download_url`。例如：

```json
{"latest_version":"0.51","minimum_version":"0.50","download_url":"https://example.com/tuan-tuan-island/latest"}
```

發現新版本會顯示像素風更新提示並開啟下載頁；舊版伺服器拒絕也會顯示更新入口。預設網址留空，因此未配置時不會連外檢查。現階段提示與瀏覽器下載入口已接通，尚未自動替換執行檔；簽章驗證、SHA-256、回復及實際發行網址仍待 T081 完成。

## 執行

以 Godot 4.7.2 匯入 project.godot。正常啟動顯示主選單。

單機快速啟動：`godot --path game -- --local`

新版像素美術與UI：`godot --path game -- --local --village-art-preview`。0.15 交付包已預設啟用。操作說明及獨立試玩存檔見輸出資料夾。此版已有供水管網、人工林自動採伐補植、設備送料，以及耕田／播種／收割三種手推農機；台灣真實縣市地圖和後續工業設備仍在規劃。

獨立伺服器：`godot --headless --path game -- --server --port=28417 --bind=127.0.0.1 --save=/absolute/path/world.json --room-key=YOUR_TEST_ROOM_KEY`

Windows 發行檔直接開啟，無須編輯器。Linux 匯出程式使用相同參數，但不帶 `--path game`。

預設只綁定本機。區網房間需輸入至少四字元房間密碼。原型不是公開網際網路服務：已有 WSS 傳輸，仍沒有正式帳號驗證、可營運的備份保留與管理服務，尚未部署到雲端。

## 原型與設計書差異

- 作物 75～150 秒成熟，一次澆水維持至採收，方便驗證循環；季節與世界日澆水尚未實作。
- 背包使用圖示格子顯示各類物品數量，尚無有限容量、拖曳格位與實體堆疊。
- 已提供共用箱與私人箱；細分地塊權限尚未完成，拆除限物件擁有者。
- 建築以格子中心物件為基礎，牆尚未改成設計書的邊界段；小屋成本公式不得直接套用。
- 家具多數可直接選單製作，工作台範圍與解鎖尚未限制。
- 小雞已有簡單餵食、親密度與產蛋，尚無領養、多個個體或跟隨。椅子、桌子為裝飾，野餐透過公共工程完成，尚無坐下及分份共享餐。
- 使用完整快照同步作為四人原型，畫面以 100 毫秒插值平順呈現；尚未做分區訂閱、移動預測或八人負載驗證。
- 成功操作寫入本機檔案並保留上一版；尚無持久交易日誌、異地備份或正式世界租約。
- 釣魚每次等待三秒後收竿，四種魚輪流出現；尚無水域、季節和稀有魚系統。料理與產蛋時間加速供原型驗證。

## 儲存位置

一般 Windows 存檔：`%APPDATA%\Godot\app_userdata\糰糰島 原型\`。
本機世界 `world-local.json`，朋友世界 `world-friends.json`，身份 `profile.json`，備份為 `.bak`。
請勿刪除 profile.json 後覆蓋舊世界；它關係到世界內物件所有權。

原始碼和測試資料應與玩家正式世界分開。測試使用獨立檔名或 `--save` 和 `--profile` 參數。

## 0.4 居民與建造版

兩位居民阿榆與米露各有四段個人故事，獨立保存進度並解鎖四件家具。J 開故事手帳；走近居民按 E 交件。公告板修好後提供三種生活訂單，每 24 分鐘在線世界時間更新一次；不強迫每日登入。番茄可收成三次，每次需重新澆水。東北採石點讓石材可再生。

R 先選自己的家具再點新位置，箱內物品一起搬。選地板、石路或屋頂後按 Shift 拖曳，每次最多 25 格且整片須在操作距離內；材料不足或任何一格不可放就全部取消。屋頂需自己的木地板。此版本尚無批次撤銷。

主選單連線位址可填完整 `wss://`（雲端 TLS 入口）或 `ws://`（隔離內網測試）；IP 仍走 ENet。伺服器支援 `--transport=websocket` 和 PORT/GAME_BIND/GAME_TRANSPORT/GAME_SAVE_PATH/GAME_ROOM_KEY 環境變數，CLI 優先。具體 Zeabur → 騰訊流程見 [部署說明](deploy/README.md)。尚未實際部署或驗證 Docker 映像。

新增規則測試：`res://tests/test_village.gd`、`res://tests/test_building.gd`。各測試需在隔離路徑執行，不使用玩家世界。六種作物、七種加工配方、十八種建造物為實作數量；完整內容設定集中的數量是後續設計目標。


第一個合作活動「風鈴接力」：完成野餐後，在公告板旁按 G 開始。靠近金色風鈴按 E，大家共同完成十二次收集。無失敗倒數，中途離線可繼續，獎勵依貢獻者保存（離線參與者也會得到）；五分鐘在線世界時間後可再玩。完整八種派對仍在規劃中。規則與斷線／保存／重領回歸見 `tests/test_festival.gd`，兩個真實網路客戶端的競爭測試見 `tests/network_festival_client.gd`。


## 0.5 圖鑑、美術與舒適設定

L 開啟生活圖鑑：親手收成、釣魚、領取料理會記錄種類，出售後仍保留；舊背包不會直接當成曾親手取得的歷史。三個里程碑提供一次性的鈴幣與種子獎勵，兩位玩家各有進度，重連仍不能重領。

角色新增四向行走與不同居民造型，樹木、農田、作物、家具加入像素細節；靠近互動對象才顯示 E。Esc 選單可設定輕柔提示音音量（0 靜音）、減少裝飾動態、預設近遠景。設定儲存在本機 settings.cfg，測試可傳 --settings= 隔離路徑。提示音為原創程式合成，尚無完整背景配樂。

已新增圖鑑規則、兩客戶端重連領獎、四向姿態、提示音與設定，以及十八建物逐件材料與通行測試。主選單與背包仍是原型介面；正式帳號、完整內容、美術與真人舒適度驗收仍待完成。實作工作板將原驗收與局部完成分開，避免把自動測試數當整體完工百分比。
