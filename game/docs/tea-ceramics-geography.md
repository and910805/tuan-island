# 第二章茶陶地理與改編邊界

本輪是 0.38 開發中的兩處合作場景，不代表整個臺北／新北地圖或完整第二章完成。

貓空合作茶園定位於臺北市文山區貓空，鶯歌合作陶坊定位於新北市鶯歌。地圖概略位置採貓空 121.59E／24.97N、鶯歌 121.35E／24.95N，僅用於縮尺示意，不是導航座標或實際工坊地址。

交通由既有瑞芳鐵路門分支，顯示「經臺北・鐵路與市區轉乘」。這是將多段真實交通形式壓縮成遊戲旅程，不聲稱瑞芳有直達貓空列車或貓空有通往鶯歌的直達鐵路。北部礦區仍從瑞芳經九份進金瓜石，路線圖與程式已改成分支圖。

## 已核對的地方背景

- 臺北市政府農業主題網介紹貓空的茶山與製茶環境，支持茶葉產地選在文山貓空。[臺北市鐵觀音包種茶研發推廣中心](https://recreational-agriculture.gov.taipei/cp.aspx?n=A94C081005225EB4&s=7ACE19239E4703E3)
- 國立臺北大學海山學研究中心記載鶯歌製陶、原料與運輸的發展，支持將陶作合作安排在鶯歌。[鶯歌陶瓷](https://museum.haishan.ntpu.edu.tw/%E5%82%B3%E7%B5%B1%E7%94%A2%E6%A5%AD/%E9%B6%AF%E6%AD%8C/)

## 原創遊戲內容

茶茶、陶師、小栗的合作訂單、工坊位置、借罐故事、秒數、價格和回收物流都是原創遊戲規則。陶土由合作工坊供應，石材換陶土表示工坊物資交換，不表示石頭能直接變成陶土。採茶至輕／深焙的工序為遊戲簡化，並非完整製茶教學；陶罐配送三次後以一份陶土修補，是遊戲耐用度設定。

完整章節仍需補：更深入的品質差異、正式茶陶角色素材、當地歷史互動、桃園竹苗連接和更深的生產自動化。自動回程目前只替已結清訂單寄回空罐，採茶、製作、收款與領罐仍由玩家操作。
