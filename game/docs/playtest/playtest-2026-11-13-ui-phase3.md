# Playtest Report — 2026-11-13 UI 第三階段

## Test Setup

Windows 桌面透過 Computer Use 的 `@oai/sky` 實際鍵鼠操作，先玩第二階段匯出程式，再玩 `TuanIsland-UI.exe`。只使用工作區內的測試副本，不改使用者已開啟的舊「隔離試玩」存檔。測試以好奇新手、建造玩家及返回玩家的角度進行；不是多人真人研究。

改版前存檔 `work/ui-phase3/manual-before.json` 來自第一階段場景副本。改版後 `manual-after.json` 使用相同場景，另將角色放在種子攤旁、增加一株成熟蘿蔔，以便檢查交易和下一輪種植；不是自然遊玩取得的初始進度。操作日誌 `manual-live.log`，標準錯誤 `manual-live.err` 為空。

## New Player Journey

改版前：Tab 開背包，木材與數量逐字往下排列，必須長距離捲動。B 開建造只有長按鈕列表，成本雖可讀但未顯示持有量。選木地板並點附近空地成功，木材 12 → 10，出現「放好了木地板」訊息，保存於副本。

改版後：按 4 採收展示蘿蔔，畫面出現 +1；E 就近開小栗商店，切換「出售」，按鈕寫明出售全部 1 件、共 24 鈴幣。點擊後鈴幣 120 → 144、持有量歸零且出售按鈕停用，仍留在出售頁。切回購買，買蘿蔔種子後鈴幣 144 → 132。Esc 回世界，2 播種、3 澆水，看到幼苗與成功回饋。

Tab 重開背包，物品名稱數量橫向清楚排列；點「種子」分類後顯示七個種子／樹苗品項。B 選需 20 木材的共用箱，放置回應「材料不足」，畫面沒有建物；再選木地板於同一空地放置成功，木材 12 → 10。J 手帳顯示阿榆、米露肖像、故事進度與材料需求。最後使用視窗關閉快捷鍵保存退出。

## Loop Map

返回測試：重新啟動同一 Windows 執行檔讀取 `manual-after.json`，看見鈴幣 132、已放置木地板及繼續生長的蘿蔔。Tab 背包確認木材 10、石材 4、纖維 10、蘿蔔種子 5；存檔中的 harvests=1、builds=1。重載沒有備份復原或引擎錯誤。最後關閉背包，保留「糰糰島 介面第三階段」視窗供使用者試玩。

成熟作物 → 採收 → 商店出售 → 鈴幣 → 購買種子 → 播種澆水 → 下一輪作物。建造選配方 → 顯示持有／所需 → 成功放置扣料或缺料拒絕 → 世界外觀改變。原世界規則不變。

## Changes Implemented

新增共用暖紙 UI 主題與既有像素圖集圖示。整理 HUD，顯示鈴幣、背包／建造／手帳／選單，非操作時收起短訊息。背包五分類、商店買賣分頁、建造四分類、種子選擇卡片、居民任務卡片與共同工程進度條。共同彈窗加入背景遮罩、固定標題與關閉、可捲動內容、底部操作回饋。修正文字初始寬度造成的視窗高度錯誤。
