## Best Moments

兩個實際玩家程序看見同一筆建物結果；錯誤請求沒有多扣材料。介面在採收後出現目標完成標記，世界不是只有靜態展示。

## Friction and Bugs

1. 主選單名字標籤在水平容器內被壓得太窄，換行使輸入欄過高並擠出頁面。
2. 主選單的歡迎訊息被 HUD 設定移到密碼欄位置。
3. JSON 載入把物品數量還原為浮點型別，字典相等檢查失敗。
4. 網路移動最後一個停止封包遺失時，原先可能持續行走。
5. 使用程序內固定物件 ID 當請求前綴可能在重啟時與舊收據碰撞。

## Changes Implemented

固定名字標籤最小寬度、分開主選單與 HUD 訊息位置；載入時驗證並正規化物品整數；移動輸入增加逾時；請求 ID 使用每次啟動的新隨機識別。增加門、屋頂、窗牆、桌椅，建造清單改為可捲動。
