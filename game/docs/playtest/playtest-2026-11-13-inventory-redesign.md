# 格子背包重製：桌面試玩與設計驗證

## Test Setup

Godot 4.7.2 Windows 匯出，使用 Computer Use `@oai/sky` 的視窗與鍵鼠操作。先檢查上一版真實背包、商店和建造介面，再操作重製版。後者從上一版試玩存檔複製成 `work/inventory-v2/manual.json`，角色有 132 鈴幣、木材 10、石材 4、纖維 10、蘿蔔種子 5、萵苣種子 3、小麥種子 3、樹苗 2。沒有改動使用者原存檔或核心資料格式。

## New Player Journey

舊版檢查確認使用者提出的問題：背包是大量長矩形；材料和魚類沒有圖，作物只是縮小的種植圖；商店重複資訊和交易按鈕；建造看不到家具輪廓；工具列全是等重文字按鈕。這些是視覺與互動結構問題，不能以通過功能測試視為已完成風格重設。

重製版按 Tab 開啟背包，HUD、工具列與短訊息暫時隱藏；木框羊皮紙居中，底部保留操作提示。木材格顯示 10，右欄也顯示持有 10。點種子分類，看到七種既有種子／樹苗；蘿蔔種子 5 與存檔一致。點胡蘿蔔種子，右欄顯示持有 0、成熟 105 秒、購入價 20 鈴幣。按右方向鍵轉至馬鈴薯種子，顯示 150 秒與 25 鈴幣；滑鼠仍停在胡蘿蔔格，其懸停淺綠與選取森林綠可明確區分。

按 Tab 關閉，HUD 與工具列恢復。按 4 選採收，點身旁成熟蘿蔔，出現 +1 成功回饋。重新開背包，蘿蔔圖示從零庫存淡色轉為完整色，格子顯示 1；點選後右欄顯示持有 1、出售價 24。Esc 關閉恢復世界，保存退出後再次啟動相同 Windows exe 與試玩存檔，按 Tab 確認蘿蔔 1、木材 10、蘿蔔種子 5、鈴幣 132 均保留。交付時將背包留在桌面開啟。這些是實際鍵鼠操作，不是僅建立靜態畫面。

## Loop Map

世界採收 → 原 Session 更新背包 → 原存檔保存 → 新格子讀取同一 inventory → 查看用途／價格 → 關閉回世界。分類與選取只改本地 UI，沒有新增傳送封包或寫入背包。

## Scores

僅評本次直接觀察的背包，不替尚未重設的整套 UI 打分，也不代表真人玩家研究。

| 面向 | 舊版 | 重製版 | 依據 |
| --- | ---: | ---: | --- |
| 圖像辨識 | 3 | 8 | 28 品項都有同尺度 PNG，種子袋與收成外形分開 |
| 遊戲風格一致性 | 4 | 7 | 像素木框、紙底與森林綠選取，其他選單仍未同步重設 |
| 操作與資訊層級 | 5 | 8 | 格子只放圖與數量，名稱、用途、價格集中右欄 |
| 閱讀與遮擋 | 5 | 8 | 開背包收起 HUD，提示固定底部，四尺寸測試與截圖 |

四項平均 4.3 → 7.8。優點是完整道具外形、選取與懸停可區分、採收數量與詳情一致。待續是其他介面的同風格改造，以及更多玩家對圖示辨識的回饋。

## Friction / Bugs

第一輪圖集實際帶半透明白底，原本只檢查檔案存在、尺寸和圖形非空未能擋住。實景檢查發現後用內建 image_gen 去背，另加入來源與成品 alpha 檢查；舊白方底反例必須失敗。另一個問題是木框中心透明，修補後又出現九宮格中心拼接條紋，最後將可重複中心改為完全不透明、單色紙底，木紋保留在邊框。

## Changes Implemented

新增可重用 `item_slot.gd`、`inventory_panel.gd`、`inventory_pixel_theme.gd`、`inventory_item_art.gd`。採用 Control/Container、GridContainer、TextureRect 與 StyleBoxTexture，32px 圖示在格子整數放大 2 倍、詳情 3 倍，最近鄰顯示。五分類保留 28 個 ID，零庫存仍能查看；超大數量完整顯示到存檔允許的 10 億，不縮寫改值。數量刷新不重建格子、不丟焦點。Tab 在 GUI 焦點導航前處理，Esc 也保留。

## Before / After Evidence

輸出目錄 `before.png` 是第三階段舊背包；`backpack.png` 用本次實際試玩後的存檔副本由同一 Windows exe 擷取，顯示木材 10、蘿蔔 1、132 鈴幣。`showcase.png`、各尺寸展示圖使用明確人工配置的全道具存檔，不當作自然進度。桌面操作畫面在對話中顯示；日誌在 `work/inventory-v2/manual.log`。

525 項相關測試與主題測試通過。四種邏輯視口及匯出截圖為 1024×640、1280×720、1280×800、1920×1080。八個核心檔案 SHA 不變，第三階段 28 個輸出檔也保持原狀。詳見 `docs/inventory-v2-verification.md`。本輪沒有新增手機遊戲或重做跨機壓力測試。
