# Playtest Report — 原型 0.3 種樹、地圖與存檔

## Test Setup

固定俯視 Windows 原型；使用隔離世界、原生引擎渲染、四個獨立客戶端及打包伺服器。桌面仍鎖定，沒有執行真正滑鼠鍵盤試玩；好玩度與暈眩舒適度仍未驗證。

## Loop Map

砍成熟樹取得 6 木材、2 纖維、1 樹苗 → 種到空地 → 世界有人時成長 180 秒 → 再次採集。未成熟樹苗可由原種植者收回；成熟樹為共享資源。農田採收後可由原開墾者恢復草地，讓布局可改變。

## Evidence

- 世界規則 64 項、生活系統 45 項、再生系統 43 項、存檔結構 69 項、介面 53 項，共 274 項檢查通過。
- 四個客戶端各運行約 375.1 秒，完成四輪真實時間蘿蔔成長、兩輪真實時間樹木成長與採集。未加速世界時鐘。每位最後應有 4 蘿蔔、24 木材、2 樹苗；結果另由保存世界核對。
- 種樹測試使用 0.3 種樹版打包伺服器；同輪後續新增的地圖與巢狀存檔驗證另做回歸，沒有把這次六分鐘測試稱為全內容長時間測試。
- 玩家身上、箱子、作物、料理、樹木與座標欄位的畸形資料會在載入時拒絕。20 類損壞樣本都不替換目前世界、不改寫原始檔。
- 備份恢復後第一次保存不再把損壞主檔覆蓋到有效備份；原檔留在 `.rejected-...`，以便查明問題。
- 料理競爭測試曾因先進入的測試客戶端先取走成品，讓另一個測試直接讀已消失欄位而失敗。加入測試專用準備屏障，兩方先查看初始內容再競爭。產品規則仍由伺服器裁定，沒有為測試放寬領取條件。

## Friction and Changes

補固定北向地圖，顯示玩家、朋友、農田、建物與渡口；按 M 開關。地圖是全島概覽，尚無路徑導航、地塊權限編輯或地圖傳送。實際渲染圖已檢查在 1280×800 畫面內，文字及地圖未超出面板。

農田原本只能擴張，不能回復，現在空田可收回；不允許刪除尚有作物的田。樹木成熟前檢查在線玩家足部附近，避免新生碰撞把人困在樹中。離線玩家不阻擋成長，重連若被阻擋則回到安全渡口。

## Limits and Next Experiment

六分十五秒不是八小時壓力測試，也不是不同實體電腦試玩。全量快照仍是四人原型方案。下一輪應由真人在解鎖桌面後走完種植、建屋、釣魚、查看地圖、離開重連的 30 分鐘路線，記錄鏡頭舒適度與互動理解；公開服務前還需要正式身份、傳輸保護、維運與長時間測試。
