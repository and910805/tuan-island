# Playtest Report - 2026-11-13 生活互動與原型 0.2

## Test Setup

本輪擴充釣魚、料理、雞隻照料、私人箱與共同野餐。遊戲規則使用隔離存檔；連線測試啟動兩個獨立 Windows 客戶端與專用伺服器。桌面仍鎖定，因此尚無真正滑鼠鍵盤操作的玩家試玩；主觀好玩度與暈眩舒適度不評分。

## New Player Journey

自動化從播種與採收進入料理，再檢查共享領取、取消退料、飼料產出、餵食、產蛋、釣魚與交付野餐。成長測試使用可控制世界時鐘驗證規則，與下述真實時間連線測試分開記錄。

## Loop Map

蘿蔔 → 湯；小麥 → 麵包與飼料；飼料 → 親密互動與雞蛋；料理 → 共同野餐與渡口彩旗；魚和雞蛋 → 鈴幣 → 新種子。私人箱保護個人物資，共用箱與石灶允許成員協作。

## Friction and Changes

原先權威位置每 100 毫秒更新會讓鏡頭階梯式前進，已加入固定 100 毫秒插值，角色與鏡頭使用相同視覺位置，停止後不無限拖尾。增加整數近遠視野切換，預設角色較清楚的近景；使用者按 Z 主動切換，不做自動縮放。

原先最近的箱子可能壓過更靠近的居民互動，已將公告板、商店、雞隻與家具共同按距離選擇。建造清單、背包與商品列表增加捲動，新增內容不把面板撐出視窗。屋頂改成進屋時淡化整片連通區域，避免不同格子半遮擋角色。

同時離線曾出現對已關閉通道送資料的錯誤。現已關閉不需要的玩家間轉送，送資料前確認對方連線仍有效；測試也改為看到執行錯誤就判失敗。重跑雙客戶端情境通過且無該錯誤。

保存失敗時，離開選單現在會提供重試或保留上次存檔後離開，不會假裝最後一次保存成功。料理工作保存投入原料與原定產量，避免日後調整食譜時造成錯誤退款。

## Before and After Evidence

原生渲染已檢查近景可辨識人物、雞隻、家具及作物。建造展示使用自動化建立的隔離存檔，呈現實際渲染結果，並未聲稱是人工遊玩建成。新世界仍從空地開始。

## Next Highest Impact Experiment

以 0.2 打包版重新跑跨平台料理與私人箱測試，繼續四人穩定性驗證。桌面可操作後用真實輸入走完採集、建屋、出貨、餵雞與釣魚路線，確認 E 互動與鏡頭近景是否清楚。之後優先增加可重生的樹木與更完整的施工流程。
