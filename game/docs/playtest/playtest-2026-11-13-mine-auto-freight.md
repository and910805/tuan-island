## 建造者與回訪玩家循環

人工林木炭 → 採掘機 → 礦料帶 → 礦層私人箱 → 定期寄運 → 渡口私人箱 → 供水與原料帶 → 水力加工 → 灑水器擴田。自然流程兩批各4銅在玩家第五層時自動寄出；未以背包或手動裝車替代。回家加工4接頭、其中2個進灑水器；重開保留成果。

每人只能一條安排及一張貨單，不是完整多線物流；保留量讓玩家留料，自動滿批才派車。既有手動草稿優先。要在持續滿批的自動路線中開始新手動寄運，先暫停自動、等途中貨送達。空草稿可取消，有貨不能直接刪單。原箱不在原格會等待；放回同一箱可恢復，新建箱須明確重新選定。

## 原生實玩與改善

兩份自然旅程存檔隔離副本，站位與開面板由腳本安排。第一份以滑鼠將保留量0改1，觀察開始鍵停用，儲存後可用。啟動自動寄4銅，立即暫停仍完成當車，來源8→4。抵達的4銅被家中現有輸送帶送入水力加工台；當時木材0，機器正常等料。背包銅16未變。

重開第二份確認保存。原生手動裝5銅使背包16→11，卸回回16，再取消空貨單。回到自動卡仍保留原設定，啟用後來源4扣保留1只剩3，未達批量4而等待。兩次Esc皆回到世界HUD；原生E／Tab及改鍵不在本次已驗證範圍。

初版小解析度裁切主要按鈕：調整內容間距並把運送小車放在雙箱之間，卡片由590縮到510高，保留80px礦物格。停用控制仍保留選中礦物的綠框。原生發現四個收貨箱時舊手動頁發車按鈕裁切，將編輯頁調到550高，三解析度測試與重開原生操作確認完整可見。
