# 居民生活第四階段：小栗的島上日常

## Test Setup

Windows 原生匯出程式，Godot 4.7.2。沿用 UI 重製版的隔離測試存檔副本，保留舊兩居民 stories 格式，預放一株成熟蘿蔔，起始採收次數 0、蘿蔔 0、萵苣種子 3、鈴幣 132。這是用於快速測試交件的場景，沒有把預放的成熟作物算成完整種植等待試玩。

## New Player Journey

實際鍵鼠操作：選工具 4，採收 41,32 的成熟蘿蔔，出現採收成功提示；靠近攤位按 E，選「和小栗聊聊」，確認蘿蔔 1/1、完成次數 1/1；交件後鈴幣變成 167。打開 Tab 背包，蘿蔔回到 0，萵苣種子增加為 5。保存離開，重開同一存檔：167 鈴幣與小栗 1/4 保留。第二章交件被尚未修橋條件拒絕，沒有額外發錢。J 手冊可切到小栗、查看目前第二章和第一章回憶。

四段故事的完整規則以隔離世界測試驗證；桌面人工操作只完成第一段並驗證第二段失敗，不宣稱已在桌面跑完全部四段。

## Loop Map

親手採收與交蘿蔔 → 萵苣種子 → 修橋與多樣收成 → 料理與邀請卡 → 野餐、補植與歸屬。

獎勵全部使用既有鈴幣、作物種子和樹苗。沿用現有物品 ID、背包數量格式及 quest 交易回呼。小栗在原攤位呈現一次，E 仍先開商店。

## Best Moments

採收後即可完成第一份委託；小栗從記錄客人口味到把貨單改成邀請卡，獎勵仍能用回農作。重開遊戲後，可以讀到已完成的對話，而不必重交材料。

## Friction / Bugs

新增第三居民後，手帳底部的葉片曾碰到最後一行章節文字；已保留更大的紙頁底部空間與穩定書框高度。從居民對話開手帳原先會跳回阿榆，現在直接開同一位居民。長篇交件提示曾碰到工具提示，已改為依文字高度向上排，並加入四解析度不重疊測試。

## Changes Implemented

- 小栗四章、三位居民合計十二章；不新增物品種類。
- 商店的對話入口、手帳第三書籤、完成回憶與同居民導航。
- 舊存檔補小栗 0，保留原故事進度；已知章節範圍與未知居民鍵驗證。
- 連線協定 6，避免新客戶端加入不認得小栗的舊伺服器。客戶端與伺服器需一起更新。
- 分別輸出 Windows 與 Linux 程式；Linux 本輪只有匯出檢查，網路整合使用本機 Windows Godot 行程，未宣稱 Linux 匯出程式已實跑。
