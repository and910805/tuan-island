# 糰糰島：小島生活 UI 重製

## Test Setup

Godot 4.7.2、GDScript、Windows Compatibility renderer。從舊背包版本的試玩存檔複製出 `work/ui-cohesion/manual.json`，初始鈴幣 132、木材 10、石材 4、蘿蔔種子 5、蘿蔔 1；所有自動截圖各自使用副本。桌面操作另用 `playthrough.json`。沒有覆寫先前階段的輸出包或使用者原存檔。

## New Player Journey

以第一次找工具的玩家、挑選家具的建造玩家、回來查看故事的玩家三種角度審視。舊 HUD 有整排等重文字按鈕，暫停選單是長直列，建造只有小縮圖或文字，手帳將所有人混在長捲動頁。新版本把日常工具留在底部圖示槽，次要功能放入生活抽屜；建造、商店、手帳與居民對話各有布局。

原生桌面實際操作：靠近小栗按 E，買一包蘿蔔種子，鈴幣 132→120、種子 5→6；切換出售，售出一個蘿蔔，鈴幣 120→144、蘿蔔 1→0，售出按鈕隨即停用。按 B 選木地板並放置於 44,32，木材 10→8，島景顯示新地板與成功提示。按 J 切換阿榆、米露，正確顯示各自台詞、章節與現有材料。按 Tab 開啟背包並切種子分類，數量與交易結果一致；Tab 返回島上。透過 Esc 抽屜進入舒適設定，再返回保存離開。

重新啟動同一個 Windows 匯出程式與隔離存檔，實際查看背包：鈴幣 144、木材 8、蘿蔔種子 6、蘿蔔 0，島上新地板仍存在；存檔 JSON 與畫面一致。兩次執行的 stderr 無錯誤。未在此回合手動提交居民委託或測試跨機連線，這些不列為桌面試玩成果。

自動截圖採執行 Windows 匯出程式、打開對應介面後擷取 viewport 的方式，不是繪製概念圖。圖庫使用同一份初始測試存檔，與上述交易後的桌面試玩存檔分開。

## Loop Map

工具欄選擇 → 點世界格子 → 原 Session 指令 → 世界及庫存回饋 → 原存檔保存。

小栗商品目錄 → 選物品 → 右側明確顯示數量與總價 → 原買賣指令 → 同頁更新庫存與鈴幣。

居民索引 → 當前委託／已完成回憶 → 到居民旁交件 → 原故事進度與獎勵。沒有新增虛構好感度、季節或體力資料。

## Friction / Bugs

第一次實景檢查發現手帳材料文字逐字換行、對話的交件鈕被推到捲動區外，雖然視窗邊界測試通過，仍不符合閱讀要求。改為整組材料圖示與不換行數量，並新增材料文字與交件可見性測試。

家具縮圖放大後與名稱交疊，已調整繪製原點與圖格留白。商店初稿過高，改為短目錄。手帳初稿只有色塊雙欄，後續換成真正的皮革像素書框，文字避開書脊。收藏原本仍是長按鈕清單，改為圖像里程碑卡；未達成時顯示進度，不顯示大型停用按鈕。

快捷圖示放大後，離開按鈕曾被推入捲動區；已固定在抽屜底部。小／大視窗原先沿用固定攝影機錨點，已改為依視口置中，並驗證點擊格位在兩種縮放下的轉換。

首次平行啟動兩個匯出截圖行程曾出現 OpenGL shader 初始化錯誤，截圖流程改為逐個啟動，最終紀錄要求無引擎或腳本錯誤。

## Changes Implemented

- HUD：日期、天氣與鈴幣角落牌；可收合心願便箋；移除頂端重複長按鈕。
- 工具欄：木框九格工具圖，數字鍵與 F 標記，選中用途提示。
- 建造：實際物件縮圖、分類、材料持有／所需與解鎖條件；預覽與島上共用家具素材。
- 商店／種子／料理／箱子：商品格與選取詳情，沿用原交易和加工／存取回呼。
- 手帳：居民索引、原角色台詞、章節、材料、目前委託與已完成回憶，套用像素書框。
- 生活抽屜、舒適設定、收藏、活動、牧場、訂單與指南各自配置。
- 背包保留格子與原五分類，統一外框與分類圖示。
- NPC 與地標名稱使用描邊文字，當前可互動對象顯示小 E 鍵帽。
- 淡入與懸停亮度回饋遵守「減少裝飾動態」；不加入鏡頭搖晃。

## Before / After Evidence

`outputs/小島生活UI重製/全部介面畫面.html` 集中呈現 18 種介面、四種解析度與舊版對照。最終自動截圖涵蓋 1024×640、1280×720、1280×800、1920×1080。全部使用 Windows 匯出執行檔，沒有用圖片合成替代遊戲實景。

八個核心檔案（world、session、save_schema、village、festival、collections、island_map、soft_audio）雜湊與基準一致。碰撞、配方、物品 ID、任務、背包儲存與多人封包邏輯保持原樣。新版以獨立預覽匯出交付，原始專案使用 `--village-art-preview` 啟用。
