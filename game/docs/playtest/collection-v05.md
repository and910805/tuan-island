# 0.5 生活圖鑑與里程碑驗證

圖鑑由世界伺服器記錄每名玩家親手收穫、釣到和領取的品種。不同玩家使用同一座小石灶時，料理記在領取者的圖鑑。飼料仍可照常製作。載入 0.4 存檔會補上空白圖鑑，原有背包、計數和魚種輪替進度會保留。

| 里程碑 | 條件 | 一次性獎勵 |
| --- | --- | --- |
| 菜園初收 | 收穫 3 種作物 | 60 鈴幣、2 番茄種子 |
| 島岸魚譜 | 釣到 4 種魚 | 100 鈴幣 |
| 島上家常菜 | 領取 3 種料理 | 80 鈴幣、2 胡蘿蔔種子 |

里程碑可從任何位置領取。進度、獎勵和領取記號使用世界既有保存流程。測試涵蓋保存失敗後的回滾與重試、同一請求的回放、重登和收據清除後的防重領。

使用 Godot 4.7.2 無畫面執行 `--headless --path game --script res://tests/test_collections.gd`，81 項檢查通過。另執行 world、life、regrowth、save_schema、village、festival、building 七套既有回歸，336 項檢查通過。圖鑑測試使用系統暫存目錄，完成後清除測試存檔。這份紀錄來自自動測試。

使用 ENet 連接本機伺服器的兩個獨立客戶端均通過網路測試。兩個角色持有不同的三種作物紀錄，各自連續送出兩次領獎，第一筆成功，第二筆遭拒。以相同身分重連後，兩個客戶端各自讀到 180 鈴幣和 2 番茄種子，第三次領取仍遭拒。磁碟存檔顯示兩個角色各有一筆菜園初收領取記號，世界共提交兩次操作。
