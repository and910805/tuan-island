使用 Computer Use 的 `@oai/sky` 控制獨立匯出的 Windows 試玩版。此版使用 `TuanIsland-Isolated-Manual-05` 專用資料目錄，與正式遊戲存檔隔離。

已觀察到：進入新本機世界；鋤地成功提示；選種子播種後蘿蔔種子 5 → 4；澆水成功提示；放置木地板後地面顯示木板、木材 12 → 10，並勾選「放置一件自己的家具」目標。

後續畫面多次切換到其他應用程式，未繼續搶占桌面焦點。採收及圖鑑、舒適設定的完整鍵鼠操作尚未確認，不能把自動化測試或預設場景擷取算成這些流程的人工驗收。未給出真人舒適度或趣味性評分。
