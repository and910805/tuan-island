# 0.5 村落美術與四向步行驗證

原創整數像素圖用帽型、髮型和服裝辨識玩家與居民。農夫戴草帽，阿榆用側分髮與淺色圍裙，米露用髮髻、頭巾及圍裙。樹冠以階梯輪廓與多層葉色表現。泥土深淺標示水分，作物成熟以淺金十字標記，沙發與長椅使用不同的布面和木紋。

步行以畫面位置的位移推導四向朝向，步伐相位按行走距離推進。站定保持最後朝向，快照跳位略過步行。減少動態開啟時手腳擺幅最多一像素，頭身維持固定高度。關閉時手腳擺幅最多兩像素，頭身起伏一像素。

Godot 4.7.2 圖形模式於隔離存檔產生 `work/art-v05-village.png`，以 1280×800 檢視居民、農地、家具與樹冠，並修正野餐旗幟覆蓋公告板及居民文字的圖層問題。姿態測試 27 項全數通過，既有 UI 測試 101 項全數通過。桌面鎖定，未進行真人試玩或移動舒適度評分。

第二輪縮小世界標籤，依目前 E 互動優先順序只顯示最近可觸發項目的按鍵，其他地點顯示簡短名稱。風鈴標籤置於右側，鄰近居民的名稱置於左側，避免遮住風鈴或互相重疊。以同一隔離村落存檔比較 `work/art-v05-labels-before.png`、`work/art-v05-labels-2x.png` 與 `work/art-v05-labels-1x.png`。1× 採 14 px 字級，2× 採 11 個世界像素，兩種圖形擷取皆可辨識風鈴和米露。第二輪執行當時的 UI 測試為 95 項，全部通過。
