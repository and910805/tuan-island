## 新手、建造者與回訪玩家循環

開通第五層 → 礦務站告知新圖樣 → 回家以木板、銅接頭、石材、樹脂製作 → 在指定礦脈旁放置 → 林業木炭由帶進料 → 採料進私人箱 → 手動裝礦車 → 回家加工 → 灌溉擴田。

自然流程675次嘗試、668次成功、7次為繼承的預期拒絕，步行2,285格；3,286項檢查通過。共加速1,488世界秒，不能當作真人遊玩時間。玩家在第五層時，第四層兩批共產出8銅礦；沒有手動補料代替輸送帶。取出並裝車寄回家後，水力加工台產出4接頭，其中2個進原灑水器配方，其餘2個保存；新田有實際澆灌與重載證據。

每個礦層只指定一個機器工作面，另外兩處仍可手採。手採與機器共用該點冷卻；已開始的機器工作會保留該點，避免兩次計算同一份礦。採掘使用世界時鐘，無玩家在線不持續消耗。每人跨區最多2台，正式長線經濟仍需平衡。
