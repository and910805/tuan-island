# 糰糰島 0.4：居民、建造與風鈴接力

範圍：Windows 原生 2D 四人生活遊戲、Linux 伺服器、隔離自動化測試。桌面仍鎖定，無法完成真實滑鼠鍵盤試玩，因此本紀錄不給「好玩」「不暈」或真人上手分數。渲染截圖是遊戲引擎的實際畫面；展示村莊由測試資料建立。

## 本版內容

- 六種作物：三種原作物加胡蘿蔔、馬鈴薯、三次收成的番茄。
- 七種加工配方（六料理與飼料）、十八種建造物。
- 阿榆、米露各四段個人故事，四種家具解鎖、J 手帳回看。
- 三種世界日訂單，每 24 分鐘在線世界時間更新；公共採石點可再生石材。
- R 搬動自己的家具及滿箱，Shift 拖曳一次鋪最多 25 格地板、石路或屋頂。
- 第一種合作派對「風鈴接力」：野餐後從公告板開始，一至四人接力收集十二枚風鈴，無失敗倒數，參與獎勵保存；每五分鐘在線世界時間可再玩。
- WSS 客戶端、WebSocket 伺服器、部署環境變數與 Zeabur → 騰訊搬遷說明。

## 回歸與競爭情境

規則測試覆蓋：個人任務不共用進度、舊階段不可重領、委託扣料、番茄三次收成且每次澆水、可再生石材、訂單刷新、批次建造整筆驗證與扣料、家具所有權、滿箱搬移不複製、保存失敗的狀態回復。

接力測試覆蓋：公共路徑可達、距離限制、兩人同搶只算一次、中途保存重載、最後一步保存失敗不發獎、離線貢獻者仍得獎、重送不重複、冷卻隨世界暫停、參與者身份只傳公開 ID。使用兩個獨立客戶端競爭最後一枚風鈴，再核對磁碟總鈴幣；不是只驗證畫面上的成功提示。

介面測試覆蓋固定 1280×800 的選單／滾動容器邊界、居民／訂單／故事／派對面板、操作到 Session 的實際路徑、拖曳施工從按下到放開、放開在 HUD 時取消、開視窗時取消施工預覽。修正了批次施工的 GDScript 型別推斷錯誤與跨 GUI 放開可能卡住的問題。

兩個 Windows 測試客戶端連到匯出的 Linux 伺服器，分別檢查 ENet、WebSocket，以及帶憑證驗證的本機 TLS 代理。這些不是 Zeabur 實際部署測試。完整數字與封包雜湊記錄於發行包旁的 `糰糰島_驗證紀錄.json`。

## 尚待完成

真人第一小時試玩、不同實體電腦跨網路驗收、八小時穩定性、正式帳號與房間管理、實際 Zeabur 部署、Docker build/run、完整 12 居民與八種派對、原創完整像素美術／動畫／音樂、季節與更多區域、細分地塊權限與八人負載。現在是擴充中的可玩原型，不能作為完整商業版驗收。

下一輪先以實際玩家能否自行找到居民、完成第一次風鈴接力、理解拖曳失敗原因和滿箱搬移為試玩目標；不以自動化通過率代替樂趣與舒適度。
