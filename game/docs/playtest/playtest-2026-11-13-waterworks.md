# Playtest Report — 2026-11-13 水力加工

## 測試設定與範圍

Godot 4.7.2／GDScript，0.32、協定 28、世界格式 11。本輪補上既有礦料、木材、供水及輸送帶的可持續加工環節；沒有縮減原 39 章、T001–T096、P0–P5 全遊戲目標。使用 game-playtest-lab 與 computer-use 技能。

原生操作使用隔離的自然旅程存檔副本，初始站位與面板由擷取腳本安排；沒有改使用者存檔。完整起步至採礦／加工旅程由伺服器權威操作與逐格行走腳本完成，與原生鍵鼠證據分開。

## 玩家旅程與循環

新手沿既有農作、林業和北部旅行取得材料，完成第三層抽水工程，製作並放置水力加工台。兩條輸入帶分別餵銅料和木材，一側接自己的水桶與水管，一側送出成品。自然旅程 516 次嘗試、509 次接受、7 次繼承的預期拒絕，1,776 格步行、2,522 項檢查；共加速推進 1,134 世界秒，不代表真人遊玩耗時。

採銅 → 人工林木材 → 供水及雙進料 → 12 秒加工 → 銅接頭 → 原灑水器套件 → 新田灌溉。兩枚自然產出的接頭都進入原配方，沒有手動補水／投料替代自動產線。保持手動配方，避免舊玩家必須先造新機器才能繼續。

原生滑鼠逐一驗證 5 件銅料與木材扣量、啟動、停用後完成當批、退料、排空餘水；成品由帶送到私人箱。重開副本後以滑鼠停出料帶，製作一批並手動取回，保存中背包銅接頭恰為 1。Esc 回到世界與快捷欄。E 注入沒有開啟互動，不能宣稱原生鍵盤或改鍵通過。

## 實測發現與修正

初版 1024×640 有不必要的內部捲軸：調整面板高度後消除。原機器預覽靜止：改成與加工狀態連動的獨立四幀 AtlasTexture，低動態靜止。狀態變兩行會移動啟停鈕：保留固定文字區高度。管網更新會覆寫操作提示：只在所有權／距離情境改變時重設說明，保留領取收據；成品區新增背包數量。

建造與工作台顯示抽水工程解鎖要求，輸送帶新增銅料與銅接頭圖示並改為四欄網格。來源／目的地可辨認加工台與料槽已滿，避免明明能接的機器卻顯示不相容。

## 驗證證據

81 套／18,283 項 Godot 檢查通過；完整清單與日誌在 work/waterworks/tests.json。UI 使用真實 Main／Session，但發出 Control 訊號與直接呼叫互動處理，不冒充原生鍵盤。三尺寸為 1024×640、1280×800、1920×1080；桌面遊戲無手機版，390px僅驗收預覽頁。

自然流程、ENet、原生操作、畫面與匯出各有獨立 evidence 檔。Windows、Linux 匯出與 HTTPS/WSS 相容的最終結果以交付 verification.json 為準；本文不把本機測試寫成 Zeabur／騰訊部署成功。
