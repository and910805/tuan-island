# 第三階段 UI 驗證

`work/ui-phase3/main-stage2.gd` 保留改版前的入口腳本。`work/ui-phase3/baseline.json` 記錄它、八個核心腳本與 29 個第二階段輸出檔的 SHA-256。

## 改版前

一般 UI 109 項、第一階段預覽 UI 26 項、村莊視覺約定 109 項通過。新增的第三階段測試共 35 項，改版前有四項失敗。在 1280×800 與 1280×720 的邏輯 viewport，背包木材文字所在 Label 只有 1 px 寬，原本 29 行變成 150 行。視窗範圍、彈窗互斥、世界點擊阻擋、Esc 關閉恢復與工具快捷鍵的其餘檢查通過。

## 執行

```powershell
$godot = (Resolve-Path work/engine/Godot_v4.7.2-stable_win64_console.exe).Path
& $godot --headless --path game --script res://tests/test_ui_phase3.gd -- --profile=ui-phase3-qa --village-art-preview
```

測試以隔離快照建立角色，在兩個邏輯 viewport 檢查背包面板和文字排版。按鍵和點擊以事件呼叫遊戲輸入路徑，桌面操作及畫面閱讀由另外的試玩驗收。

## 整合期間觀察

分組背包的木材標籤在兩種尺寸均可水平排版。商店在更新持有量後保留出售分頁與鍵盤焦點。缺錢和沒有收成時對應交易按鈕停用。六種種子與十八項建物均有入口，故事鎖定配方停用；缺料配方仍可選，選擇不扣材料，實際放置由權威世界拒絕。

加入所有面板邊界檢查後，早期整合版發現公告板、居民及圖鑑面板高度達 815 px；商店及手帳在 720 px 視口也超出。既有 UI 回歸同時捕捉到部分面板和關閉按鈕超出視口。長清單由 ScrollContainer 裁切，回歸檢查會核對捲動視窗本身是否位於視口及包含它的面板範圍。

共同彈窗修正後重跑，第三階段測試 99 項、一般 UI 109 項、預覽旗標下的既有 UI 96 項、村莊預覽 UI 22 項均通過，合計 326 項。主題測試也通過，該套未輸出斷言數。彈窗測試等待兩個畫格後再檢查容器尺寸。逐套日誌位於 `work/ui-phase3/after-*.log`。
