# 村莊預覽第一階段技術配置

## 渲染與資料邊界

Godot 4.7.2 的 `world_view.gd` 是 `Node2D` 自繪場景。每格 32 世界像素，近景 2×、遠景 1×。畫面使用 nearest filtering，鏡頭偏移與角色繪圖位置取整。世界格座標透過 `screen()` 轉畫面座標，點選則由 `to_cell()` 轉回世界格。世界預覽 atlas 建議使用整數大小的來源與目標矩形，並沿用這兩個轉換。

地表先依 y、x 掃描繪製。高物件、資源、固定地標與居民玩家採用第二趟掃描，按格列由北向南繪製。同一列先畫 x 順序的資源和物件，再畫居民及玩家。角色按插值腳點的 y 所在列加入。這是手動格列排序，沒有場景樹的 Y-sort。屋頂、名稱與操作框再覆於其上。資料使用字串鍵 `"x,y"`，空間排序以解析後的整數格座標執行。直接用字串字典序會把例如 `"10,29"` 排在 `"9,29"` 前。

World 與 Session 決定碰撞、採集、建造與快照。預覽只讀取快照，atlas 對應表放在渲染層。基礎樹與石頭以 `World.base_resource()` 決定，`removed` 隱藏已採集資源，`forest` 優先決定種植樹苗與成樹。家具、耕地、玩家地板及屋頂仍由各自資料層繪製。空地花草和路緣要留在地表層，並讓玩家鋪面與作物蓋住。

## 預覽範圍與布置

預覽區為 `Rect2i(25,19,36,38)`，含 x25–60、y19–56。下表的分區是視覺布置建議，實際 tile 類別應逐格讀取現有判定。

| 區域 | 建議視覺處理 |
| --- | --- |
| 中央道路 y29–31／x35–54，南北支線 x39–41／y28–37 | 用貼地的不規則草沿、石屑或短砂紋弱化方形邊界。先從既有道路的上下左右和對角鄰格選邊，保留內部連續淺土色。 |
| 廣場 x38–44／y28–31 | 保留乾淨步行帶，讓 NPC、攤位、風鈴及短標籤優先。以地面石粉或小花處理廣場外緣。 |
| 西北 x25–37／y19–28 與西南 x25–37／y34–56 | 可給已存在樹不同樹冠。依格座標做固定變種，維持原樹根和陰影錨點。保留道路遠端與可開墾格的空曠感。 |
| 東北採石點周圍 x46–54／y22–29 | x46–51／y22–29 的基礎資源刻意留白。可用小型地表石粉引向採石點 (54,25)，保持此空區可行走及可用。 |
| 南側海岸 | 依 `World.land()` 的真實水陸鄰格產生內外彎、岸線與靜態浪邊。橢圓島在此區主要呈現南緣，實際水陸分界隨 x 改變。x49–50／y51–54 的木平台鋪在既有陸地，這兩欄的 y55 為水。船錨點 (51,55) 同樣在水域。取樣鄰格時跨越預覽邊界。 |
| 東側人工水道 x55–56 | 用河岸或淡色水紋表現。橋只在 `board` 已完成的 y29–31 取代這兩欄的水。x57–59 仍有陸地，不把這一段水道畫成外海。 |

| 地標 | 格座標 | 行走判定 |

| 出生點 | (39.5,33.5) | 保護通道 |

可走格適合貼地花、短草、小碎石、地表磨損和低對比陰影。樹幹、岩體、整面籬笆、桶、屋子與成組家具都會暗示阻擋，應留給原有障礙物與已建物件。樹冠可越過格線，但樹根必須對齊實際阻擋格。檢查種植樹移除後的畫面，避免基礎樹或新裝飾重新遮住地塊。

## 驗收畫面

用同一隔離存檔在 1× 和 2× 查看出生點、廣場、風鈴與米露重疊場景、採石方向、橋口與南岸。另比對公告板完成前後、樹採集前後，以及同一格上的玩家鋪面和作物。畫面核對應包含陸地邊緣的腳點通行、點選格與圖示對位，以及路緣在預覽矩形邊界的銜接。等 atlas 的分類介面定案後，再決定是否以合約測試驗證代表格。

## 實際渲染審閱

Godot 截圖 `village.png`、`coast.png` 和 `wide.png` 顯示不規則路緣、樹種變化、村中心地標與南岸的木平台和船。1× 與 2× 的地標名稱和 HUD 皆可辨識。展示存檔的長椅與花箱是已有阻擋判定的家具。可行走的指路牌沿用原版規則與圖像，最終展示配置移除高指路牌。遠景左緣和外海南緣仍可見預覽素材與既有地圖的過渡。這三個畫面未涵蓋風鈴活動或真人操作。
