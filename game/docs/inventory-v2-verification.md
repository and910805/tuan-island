# 背包格子改版驗證

改版前入口腳本與基線記錄在 `work/inventory-v2/`。基線包含八個核心腳本及 28 個第三階段輸出檔的 SHA-256。

## 既有介面觀察

比對第三階段輸出的 `village.png`、`shop.png`、`quests.png` 和 `build.png`。

- 工具列的八個按鈕以同一尺寸的文字呈現，選中主要靠綠底辨識。工具輪廓與清楚的選中框可讓玩家更容易掃到目前工具。
- 商店種子圖在寬卡片中偏小，持有量、單價和下單資訊多次出現在同一視線區。可讓圖示與名稱成為定位錨點，整理單價和交易狀態。
- 建造卡片缺少配方外觀預覽。可放置與缺料配方使用相近的按鈕外觀，可增強缺料狀態辨識，同時保留先選配方的操作。
- 任務展開時覆蓋村莊左側，三項目標與三顆操作按鈕視覺權重相近。可保留收合功能，展開時先顯示下一步與進度，再排列相關操作。

## 回歸命令

```powershell
$godot = (Resolve-Path work/engine/Godot_v4.7.2-stable_win64_console.exe).Path
& $godot --headless --path game --script res://tests/test_inventory_grid.gd -- --profile=inventory-v2-grid --village-art-preview
```

測試使用隔離玩家快照，涵蓋 28 個項目與五個分頁，數量 0、1、999、12345、選格和右欄、刷新保留焦點及資料守恆、Tab 與 Esc、彈窗期間世界點擊與地圖快捷鍵，以及四種邏輯 viewport 下的格子、右欄和頁尾尺寸。桌面試玩另行記錄。

## 自動化結果

格子整合測試 138 項、面板 21 項、一般 UI 109 項、預覽旗標下 UI 103 項、第三階段 UI 99 項、村莊預覽 UI 22 項，合計 492 項通過。主題套件另外通過。格子測試確認 28 個圖示均有可解碼且含圖形的 32×32 圖集區塊。框線、懸停及選中樣式有貼圖，面板與格子採最近鄰取樣。反覆開關後背包及遮罩已釋放，HUD 與任務追蹤恢復原可見狀態。日誌位於 `work/inventory-v2/`。

舊圖集的白色方底在實景中可見，右側物品詳情、格子及頁首圖示均受影響。新版畫面確認白底消失，頁首及頁尾文字在底紙上可讀。資產檢查包含每格四角與成品中心 22×22 的至少 4% 全透明像素；源圖另檢全格透明比例。舊源圖及具有透明外框的白方底反例均為 0／30，新源圖與成品皆為 30／30。另確認框圖中心像素完全不透明且為同一顏色。

最終版加入 alpha 檢查及 1,000,000,000 的顯示檢查，格子整合測試增加至 171 項，相關套件合計 525 項通過，主題套件也通過。
