# IslandFileLock

Godot 4.7 x86-64 GDExtension. Use `ClassDB.instantiate("IslandFileLock")`, then `acquire(absolute_path)`, `is_held()`, and `release()`. The path must end in `.writer-lock`. Keep the same reference for the entire write lifetime. Closing it or exiting the process releases the OS handle. The sidecar remains in place. On Linux the lock is advisory, so all writers must cooperate. Keep sidecars on the same local volume as the protected files and retain them during maintenance.

On Ubuntu or WSL with GCC, libc development headers and the MinGW-w64 x86-64 cross compiler, run `sh game/native/world_lock/build.sh` from the project root. The header is generated by the matching Godot editor's `--dump-gdextension-interface`. The extension source is MIT-licensed and the generated header includes the Godot MIT notice. The Windows and Linux binaries are staged in `game/addons/world_lock`. Run editor import before a direct script test on a fresh source checkout. Exported executables need their platform library beside the game in the exported extension path.

The lock tests cover Windows and Ubuntu WSL processes separately. They do not establish exclusion between Windows and Linux kernels on a shared mount, or on network filesystems.
