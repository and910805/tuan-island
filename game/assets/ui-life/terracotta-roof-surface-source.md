# 紅陶瓦屋頂像素貼圖

使用 Codex 內建 ImageGen 生成原創瓦面，Godot 以最近鄰將原圖轉成 32×32 PNG。放置後的屋頂、施工預覽和家園工坊同用一張瓦面。原圖與轉檔工具見 t094-terracotta-roof-art 驗證資料夾。

> Create one square seamless repeat texture tile for a Taiwanese coastal village in an original cozy 2D life simulation game. Subject: a front-facing planar field of overlapping traditional rust-red fired-clay barrel roof tiles, seen straight on from above the sloped surface. Texture only, fills the canvas right up to all edges. Design on a 32 by 32 logical pixel grid with integer crisp square pixels and a limited earthy terracotta palette. Exactly four rows of overlapping clay scalloped tile lips across eight-pixel courses, alternating staggered horizontal seams. Clear one-pixel separation between courses, warm rust and restrained highlights, some small handmade baked color variation, restrained shadows, clean readable shapes when very small. Edges wrap seamlessly in both directions: the right edge continues the left edge motif, and the bottom row transitions naturally to the top row. No external outline, border, margins, words, objects, house, ridge, gutter, side view, backdrop, perspective or gradients. Pixel game texture, not photorealistic, no extensive grime, no repeated shadows pointing in different directions.
